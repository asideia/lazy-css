### ✨ Highlights
* **🧠 LLM-Ready:** Rigid class naming convention (`vibe-[block]-[modifier]`) that AIs can easily predict and apply to raw HTML/JSX.
* **🎨 Decoupled HSL Engine:** Change your entire brand color palette or switch to Dark Mode by tweaking a single math token.
* **📦 Framework Agnostic:** Zero dependencies. Works seamlessly with React, Vue, Svelte, or vanilla HTML.
* **🚀 Production Optimized:** Pre-processed with PostCSS, Autoprefixer, and CSSNano for maximum performance.
