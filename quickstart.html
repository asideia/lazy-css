🌐 Uso via CDN (Sem NPM)

Ideal para desenvolvimento ágil, arquiteturas monolíticas e integração simplificada com LLMs. Insira o link abaixo diretamente no <head> do seu projeto:

<link rel="stylesheet" href="https://cdn.jsdelivr.net/gh/asideia/lazy-css@main/dist/lazycss.min.css">
💡 Nota de Distribuição: Esta URL aponta diretamente para a branch principal (main), garantindo que seu ambiente consuma as últimas atualizações de componentes homologadas em tempo real.

Alimente sua Inteligência Artificial

O Lazy CSS não exige que você decore classes utilitárias complexas. O grande segredo é baixar o nosso manifesto de especificação técnica unificado e injetá-lo diretamente no prompt do seu modelo de linguagem (Claude, ChatGPT ou Gemini) antes de pedir para ele codificar suas interfaces.

Compilador de Blueprint Nativo

Gera o arquivo Markdown unificado combinando as regras estritas de arquitetura e os exemplos reais contidos no manifesto do sistema.

Como Utilizar no seu Workflow Diário

  1. Clique no botão acima para baixar o arquivo compilado dinamicamente lazycss-blueprint.md.
  2. Inicie uma nova conversa ou sessão limpa com a sua LLM de preferência.
  3. Anexe ou copie integralmente o conteúdo do arquivo baixado no primeiro prompt estrutural e envie.
  4. Após a IA confirmar que absorveu o contrato das assinaturas, faça o seu pedido de UI corporativa (Ex: "Crie um formulário de cadastro de usuários administrativos usando o Lazy CSS").
